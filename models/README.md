# Example models

These `.nlogo` files are the programs GoNetLogo embeds. The server also reads model files only from `MODELS_DIR`, which defaults to this directory.

| File | Origin |
| --- | --- |
| `fire.nlogo` | Original forest-fire demo. Inspired by Wilensky's Fire model; this source is not that file. |
| `life.nlogo` | Original Conway's Game of Life demo. |
| `output.nlogo` | Original output-widget demo. |
| `termites.nlogo` | Original termites demo. Inspired by the Resnick termites model; this source is an original write-up of that rule. |
| `wolfsheep.nlogo` | Original wolf-sheep demo. |
| `edge.nlogo` | Original non-wrapping world. Eight turtles walk until `fd` stops them on the last patch inside the edge. |
| `Robby the Robot.nlogo` | Unmodified NetLogo Models Library sample. See the credit and license below. |

## Robby the Robot

`Robby the Robot.nlogo` is the classic text model from the NetLogo Models Library, tag `6.4.0`, path `Sample Models/Computer Science/Robby the Robot.nlogo`. The model's version line is NetLogo 6.3.0. The current Models Library `main` branch ships this model as `.nlogox`; this copy is the `.nlogo` file from the 6.x tag, byte for byte.

The Info tab states the following.

### Credits and references

Robby was invented by Melanie Mitchell and described in her book _Complexity: A Guided Tour_ (Oxford University Press, 2009), pages 130-142. Robby was inspired by The "Herbert" robot developed at the MIT Artificial Intelligence Lab in the 1980s.

This NetLogo version of Robby is based on Mitchell's earlier versions in NetLogo and C. It uses code from the Simple Genetic Algorithms model (Stonedahl & Wilensky, 2008) in the NetLogo Sample Models Library.

Robby resembles a simpler version of Richard E. Pattis' Karel the Robot, https://en.wikipedia.org/wiki/Karel_(programming_language).

### How to cite

If you mention this model or the NetLogo software in a publication, we ask that you include the citations below.
